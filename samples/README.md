# Sample videos

- **`sample_movement.mp4`** — a short public-domain squat demonstration. Use this with
  the app's **"Choose Test Video"** button to confirm the full pipeline without sourcing
  your own clip. (Pose detected in 213/213 frames in our test.)

- **`sample_movement_posed.mp4`** — the **expected output**: the same clip after the
  backend drew the pose skeleton. Open it directly to see what a correct result looks
  like, even before running the app.

Source: "Squat - exercise demonstration video", Wikimedia Commons (public domain),
transcoded to H.264 MP4. https://commons.wikimedia.org/wiki/File:Squat_-_exercise_demonstration_video.webm
